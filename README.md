## 🚀 Overview
**Cyberyan** is a modern full-stack monorepo project structured with **Turbo** and **pnpm workspaces**, designed for high scalability and clean separation of concerns.

## 📁 Monorepo Structure
- **`apps/api`**: Backend server powered by NestJS 11, Mongoose 9, and Swagger.
- **`apps/client`**: Frontend application built with React 19, Vite, and TypeScript.
- **`packages/shared`**: Shared package containing common TypeScript types, DTOs, and interfaces.
